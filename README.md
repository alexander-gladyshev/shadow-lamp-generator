# Shadow Lamp Generator

Генератор настенного теневого бра для 3D-печати. Из любой картинки (PNG, JPG, фото) он делает силуэт, рассчитывает четыре стенки с узором и выдаёт готовые STL. Светодиод внутри отбрасывает узор тенью на стену вокруг светильника.

Всё работает в браузере, без сервера и без установки. Картинка никуда не отправляется.

> Закрытый проект для личного использования. См. [LICENSE](LICENSE).

## Запуск

Откройте `index.html` в браузере (Chrome, Safari, Firefox).

Если браузер блокирует что-то при открытии файла напрямую, запустите локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

3D-просмотр и экспорт STL используют three.js с CDN (`cdn.jsdelivr.net`), поэтому для них нужен интернет. Трассировка и симуляция тени работают и офлайн.

## Как пользоваться

1. **Картинка.** Перетащите PNG/JPG на стартовый экран или выберите один из примеров. Подберите порог, сглаживание и толщину. Тёмный или непрозрачный фон убирается автоматически.
2. **Картинка на стене.** Задайте ширину тени, сдвиг и поворот.
3. **Светильник.** Размер основания, высота стенок над основанием, насколько светодиод утоплен от переднего края, тип светодиода.
4. **Основание и электрика.** Питание (USB-C, 2×AAA, 2×AA, 18650), толщина основания, выключатель сбоку: тумблер MTS-102 или клавиша KCD11.
5. **Стенки.** Толщина, зазор в углах, крепление винтами или на клей, открытые углы.
6. **Печать.** Минимальная деталь, точность стенки, тип перемычек для висящих кусочков.

Вкладки:

- **Картинка** — исходник, маска и контуры.
- **Стена** — точная симуляция тени (для каждой точки стены луч прослеживается до светодиода), раскладка картинки и сравнение вариантов перемычек.
- **Развёртка стенок** — четыре стенки так, как они будут напечатаны.
- **3D** — модель со светом и тенью, режим «Разнести детали».

Кнопка «Скачать для печати» скачивает zip: STL коробки основания, крышки с ножкой, 4 стенок и (для батареек) люка отсека — уже в положении для печати, SVG тени и `readme.txt` с электрикой и порядком сборки.

## Конструкция в двух словах

- **Основание** — коробка у стены. Внизу полноразмерная «юбка», на неё накладываются стенки. Выше коробка сужается пирамидой ровно по слепому конусу светодиода, поэтому своей тени на стене почти не даёт. Пирамида стоит прямо на плече юбки.
- **Электрика** — отсек под держатель батареек открывается люком в задней стенке (2 самореза M2, снаружи прижат стеной). Плата USB-C или модуль зарядки лежит на площадке с направляющими у нижней стенки; снаружи карман под штекер, чтобы кабель входил до конца. Выключатель — классический тумблер или клавиша на правом боку. Провода идут кольцом вокруг отсека, от ножки к краю крышки — канавка изнутри. Сзади пазы под саморезы.
- **Ножка** — полая, растёт из крышки основания, сужается к кончику. Светодиод сидит на кончике и светит на стену. Провода идут внутри ножки.
- **Стенки** — плоские, печатаются плашмя без поддержек. Низом крепятся к юбке винтами M2 или клеем. Углы открыты, стоек и передней рамки нет.
- **Перемычки** — висящие кусочки узора автоматически соединяются: кратчайшими перемычками, лучами к основанию или кольцами.

Подробности и формулы — в [docs/DESIGN.md](docs/DESIGN.md).

## Проверка

```bash
# смоук-тест страницы (нужен Node 18+ и Playwright с Chromium)
npm i -D playwright && npx playwright install chromium
node tests/smoke.mjs            # скачает tests/out/export.zip

# проверка STL из zip
pip install trimesh
python3 tests/check_export.py tests/out/export.zip
```
